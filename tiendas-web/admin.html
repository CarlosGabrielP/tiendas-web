          Formato del CSV

          Ver columnas y ejemplos

          Obligatorias: nombre, categoria, existencias. Todas las demás son opcionales.

          • id: identificador único (ej. vertex-05-2026). Si lo dejas vacío se crea a partir del nombre y la talla. Mantenlo igual entre cargas para no perder la foto del producto.
          • categoria: {{tienda._listaCategorias}}.
          • precio y precio_anterior: números, ej. 2499 o 2,499.00. Si precio está vacío se muestra "Precio próximamente". Si precio_anterior es mayor, se muestra como oferta.
          • existencias: número entero. 0 = el producto pasa a bajo pedido (sigue a la venta con fecha de entrega del proveedor). Vacío = sin control de existencias.
          • entrega: vacío = automático según existencias (con existencias ⚡ envío inmediato el mismo día hábil antes de las 2:00 pm; con 0, 📦 bajo pedido). pedido = siempre bajo pedido aunque tenga existencias (se pide al proveedor el viernes; corte jueves 6:00 pm; llega a nuestro almacén dos viernes después).
          • disponible: sí o no. Pon no para ocultar un producto aunque tenga existencias o sea bajo pedido. Vacío = sí.
          • talla: para ropa o tenis, pon una fila por talla con el mismo nombre (o el mismo id) y las existencias de esa talla. Se muestran como un solo producto y el cliente solo ve las tallas con existencias.
          • marca, temporada, color, forma, peso, nucleo, cara: se muestran en la ficha.
          • nivel (iniciación, intermedio, avanzado) y juego (control, polivalente, ataque): solo palas; alimentan el recomendador.
          • etiquetas: nuevo, oferta, top (separadas por |).
          • detalles: datos extra con formato Clave: valor | Clave: valor.
          • foto: vacío = usa la foto que ya tenga ese producto; o un enlace https://…: la foto se descarga a tu almacenamiento (botón «Descargar fotos») y la tienda nunca muestra la dirección de origen.
          • costo_eur: costo en euros (lo que pagas al proveedor). Si está lleno, el precio de venta se calcula solo: costo × factor × tipo de cambio de Banxico × (1 + IVA), terminado en 9, y la columna precio se ignora. descuento: % de descuento sobre ese precio.
          • url_proveedor: enlace a la página del producto en tu proveedor. Solo se ve en este panel (botón 🛒), nunca en la tienda.

          Datos de la guía

          La guía se paga con tu saldo de Envíosperros. Al generarla, el pedido pasa a «Enviado» y al cliente le llega el correo con su número de guía. El rastreo se revisa solo: cuando la paquetería marca «Entregado», el pedido cambia a «Entregado». Una guía se puede cancelar hasta 3 días después de crearla y el saldo regresa a tu cuenta de Envíosperros.
