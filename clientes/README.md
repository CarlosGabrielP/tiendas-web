# Tiendas de clientes

Una carpeta por tienda: `clientes/<clave>/` con `tienda.json`, `catalogo.js`, `img/` y, si los necesita, `legal/`, `guias/`, `contenido/`
y un `README.md` con lo propio de su operación (dominio, proyecto de Cloudflare, pendientes).

Para dar de alta una tienda usa la skill `nueva-tienda` (o `tienda-desde-instagram` si el negocio vende por Instagram).
Base para copiar: `tiendas-web/demos/demo-suplementos/`. Campos: `tiendas-web/docs/TIENDA-JSON.md`.
